# Made using AI

Playlist FLAC was created with extensive assistance from OpenAI Codex. A human directed the requirements, requested changes, and authorized release. AI generated much of the application code, interface design, automated tests, documentation, and release tooling.

The project is openly described as AI-built. Automated checks and local validation are documented in docs/VALIDATION.md. These checks are not an independent security audit or a guarantee of download correctness. Contributions and independent review are welcome.

Sockseek is a separate upstream project by its own contributors. This disclosure describes the Playlist FLAC wrapper and release preparation; it does not claim authorship of the bundled engine or its dependencies.
